# Sistema de Gestión para Refaccionaria

## Descripción

Este proyecto fue desarrollado utilizando el framework **Django**, implementando la arquitectura **Modelo-Vista-Template (MVT)**, con el objetivo de fortalecer mis conocimientos en el desarrollo de aplicaciones web modernas y aprender a trabajar con **PostgreSQL** como sistema de gestión de bases de datos.

El sistema está enfocado en la administración de una **refaccionaria** y fue diseñado para gestionar información mediante una arquitectura modular basada en aplicaciones (Apps), facilitando el mantenimiento, la escalabilidad y la organización del código.

## Características

* Página principal con información de la empresa y sus diferentes áreas.
* Módulo de nóminas para la administración del personal.
* Organización del sistema mediante aplicaciones independientes de Django.
* Implementación del patrón **MVT (Model-View-Template)** para separar la lógica de negocio, la presentación y el acceso a los datos.
* Consultas complejas sobre bases de datos PostgreSQL.
* Generación de reportes dinámicos en formato PDF.
* Integración entre Django y PostgreSQL para el almacenamiento y procesamiento de la información.
* Interfaz web responsiva y fácil de utilizar.

## Tecnologías utilizadas

* Python
* Django
* PostgreSQL
* HTML5
* CSS3
* JavaScript
* Bootstrap
* Arquitectura MVT (Model-View-Template)

## Objetivo

El objetivo principal de este proyecto fue adquirir experiencia en el desarrollo de aplicaciones web utilizando **Django** y la arquitectura **MVT**, así como aprender a diseñar aplicaciones modulares, implementar consultas complejas en **PostgreSQL** y generar reportes dinámicos en formato PDF. Este proyecto forma parte de mi proceso de aprendizaje y del fortalecimiento de mis habilidades en el desarrollo de software.
